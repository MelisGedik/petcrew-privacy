# Pet Crew privacy policy

Public privacy-policy pages for Pet Crew - Health Tracker, developed by Melis Gedik. Support: petcrewapp@gmail.com.

English: https://melisgedik.github.io/petcrew-privacy/privacy-en.html
Turkish: https://melisgedik.github.io/petcrew-privacy/privacy-tr.html

This repository contains only public policy HTML/CSS. It does not contain the app source, user records, backups or signing keys. GitHub Pages publishes main / root; .nojekyll disables template processing. No custom domain, build service, paid plan or client-side JavaScript is needed.

Edit the text in privacy-en.html and privacy-tr.html together when app data practices change. Keep both public URLs stable for the app and Google Play listing.
